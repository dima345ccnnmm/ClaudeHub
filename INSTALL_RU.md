# ClaudeHub DOORS v0.4.4

## Обновление

Замените **Doors.luau** в корне своего репозитория и обновите CHANGELOG.md / THIRD_PARTY_NOTICES.md.
Loader.luau v1.1.0 и DoorsLobby.luau v0.4.1 в комплекте не изменены; ClaudeHub.luau менять не нужно.
Файлы не публикуются на GitHub автоматически.

Перед проверкой перезайдите в игру, чтобы прекратить старые обработчики. Запускайте только один хаб:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dima345ccnnmm/ClaudeHub/main/Loader.luau"))()
```

В Home игрового модуля должна быть **v0.4.4**. До обновления файла на GitHub ссылка загружает старую версию.
После телепорта загрузчик нужно запустить повторно. Старые настройки не загружаются автоматически;
для v0.4.4 используется отдельная папка конфигов.

## Что изменилось

- Fast Interact, Instant Prompts, Prompt Clip, Prompt Reach Multiplier удалены.
- Вкладка Exploits и все её обработчики удалены, включая отключение звуков и локальные bypass/remove.
  Fly/Noclip и визуальные эффекты вне этой вкладки не затрагивались.
- Legit Speed Boost всегда даёт **+4** к текущей базовой скорости. Ползунка нет. Название не означает
  гарантированную совместимость с серверной проверкой движения.
- Под функциями нет поясняющих абзацев; рабочие статусы, Home и авторство сохранены.
- Auto Closet реагирует только на Rush/Ambush/Blitz/A-60/A-120 и перечисленные в changelog варианты.
  Eyes, Seek, Screech и Lookman его не запускают. Игрок не выходит из укрытия автоматически.
- Auto Interact: включённый переключатель **ИЛИ** удержание **R**. Значок рядом позволяет сменить бинд.
  Ignore List: выбранные категории пропускаются.

## Полная исходная логика Auto Interact

Фильтры, TriggerPrompt и основной Heartbeat-цикл скопированы дословно из присланного Main.luau Abysall.
Перенесены и исходные FirePrompt/ForceFirePrompt с резервной очередью. Для встраивания подставлены
объекты ClaudeHub и сохранено восстановление при выгрузке. Исходная лицензия MIT и FireBacon указаны.

При наличии fireproximityprompt используется он. Без него применяется исходный резервный способ:
выбранный prompt временно переносится к камере, получает временные параметры, активируется через
InputHoldBegin/InputHoldEnd и возвращается на место. Это не возвращает удалённые настройки
Instant Prompts/Prompt Clip/Reach Multiplier: отдельных постоянных переключателей для них нет.

В отличие от предыдущей переработки, полностью перенесённый цикл не имеет дополнительной паузы
ClaudeHub на открытое меню/потерю фокуса. Для остановки выключите Auto Interact и отпустите R.
Уже начатая резервная операция может завершить свои ограниченные повторы; выгрузка отменяет её
и восстанавливает временные параметры. Сервер или исполнитель могут отклонить взаимодействие.

Компиляция и локальные тесты пройдены. Живой тест в Roblox/DOORS не проводился.
