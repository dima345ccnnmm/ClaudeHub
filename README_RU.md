# ClaudeHub JJS v0.1.0

Первый отдельный модуль для Jujutsu Shenanigans на обычном Obsidian.
DOORS, DOORS Lobby и универсальный модуль в этом архиве не изменяются.

## Установка

1. Добавьте `JJS.luau` в корень репозитория `dima345ccnnmm/ClaudeHub`, ветка `main`.
2. Замените там `Loader.luau` файлом из этого архива.
3. Существующие `Doors.luau`, `DoorsLobby.luau`, `ClaudeHub.luau` оставьте на месте.
4. Войдите в JJS и выполните обычный загрузчик:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dima345ccnnmm/ClaudeHub/main/Loader.luau"))()
```

Архив сам ничего не публикует в GitHub. До загрузки обоих файлов публичная ссылка не начнет открывать новый модуль.
После телепорта запустите загрузчик заново. Автоматического queue-on-teleport нет.

## Что реализовано

- Home: профиль, число игроков, версия и время сессии.
- Character: фиксированный Legit Speed Boost +4, Infinite Jump, Third Person с настройкой минимального отдаления.
- Visuals: подсветка игроков, имя/здоровье/расстояние, фильтр союзников, цвет, прозрачность, размер текста и дальность.
- Rendering: Fullbright, Remove Fog (обычный Lighting fog, не все игровые эффекты).
- Camera: FOV, Freecam, выбор игрока для Spectate.
- Training: три сохраняемых на время сессии слота позиции, возврат, очистка слота, таймер.
- Training HUD: горизонтальная скорость в studs/s, здоровье, координаты и таймер. Перетаскивание мышью/касанием, сброс положения.
- Settings: темы Obsidian и ручное сохранение/загрузка конфигураций, если окружение поддерживает файловые функции. Автозагрузка конфигурации отключена.
- Бинды встроены в переключатели/кнопки, отдельного столбика биндов нет. Нажмите на обозначение клавиши для переназначения.

Все переключатели функций изначально выключены. Для подписей ESP отдельно включите Names / Health / Distance.

## Клавиши по умолчанию

| Клавиша | Действие |
| --- | --- |
| RightControl | Меню |
| V | Legit Speed Boost +4 |
| J | Infinite Jump |
| T | Third Person |
| H | Player ESP |
| F6 | Freecam |
| F7 | Spectate Player |
| K | Сохранить позицию в выбранный слот |
| L | Вернуться в выбранный слот |
| F8 | Старт / пауза таймера |
| F9 | Training HUD |

Freecam: закройте меню, WASD — движение, Q/E — вниз/вверх, Shift — ускорение; удерживайте ПКМ для поворота камеры.
Freecam и Spectate взаимоисключающие. При респавне они выключаются. Нет автоматического выбора другого игрока при исчезновении цели.

## Ограничения

Это клиентские инструменты, а не интеграция с серверными способностями JJS. Нет auto-block, auto-parry, комбо, манипуляций hitbox, боевых remote-вызовов или обхода античита.
Сервер может корректировать скорость, прыжки и возврат к точкам. Название Legit Speed Boost не означает гарантированной безопасности от санкций.
Во время кат-сцен игра может принудительно управлять камерой. Метки используют только доступные клиенту персонажи; одновременно отображается до 24 игроков.
Слоты позиций не сохраняются на диск и не переносятся между серверами. Не пытайтесь возвращаться в разрушенную/опасную область карты.
Обычная библиотека и дополнения загружаются с официального репозитория deividcomsono/Obsidian при запуске; требуется доступ к raw.githubusercontent.com.

## Проверки

JJS.luau и Loader.luau проходят компиляцию Luau. В локальных тестовых заглушках проверены стартовые состояния, бинды кнопок без двойного вызова, восстановление скорости/FOV/освещения/камеры, смена камеры, фильтры ESP, отсутствие персонажа, удаление цели, freecam, точки, таймер, перетаскивание HUD, респавн и очистка при выгрузке/ошибке запуска.
Проверены маршруты JJS / DOORS / DOORS Lobby / universal и повторный запуск загрузчика после ошибки.
Это не тест в настоящем Roblox/JJS: игровую совместимость необходимо проверить на месте.
