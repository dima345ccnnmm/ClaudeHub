# ClaudeHub DOORS v0.4.3

## Установка

Замените **Doors.luau** в корне вашего репозитория и обновите THIRD_PARTY_NOTICES.md / CHANGELOG.md.
Loader.luau v1.1.0 и DoorsLobby.luau v0.4.1 в комплекте не изменены. ClaudeHub.luau менять не нужно.
Архив не публикуется на GitHub автоматически.

Перед проверкой перезайдите в игру и запускайте только один хаб:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dima345ccnnmm/ClaudeHub/main/Loader.luau"))()
```

В Home игрового модуля должно быть **v0.4.3**. Пока файл на GitHub не заменён, ссылка загружает
старую версию. После телепорта загрузчик нужно запустить повторно.

## Управление

- **Auto Interact:** переключатель для постоянной работы ИЛИ удержание R для временной.
  Сканируются все подходящие prompts в пределах их собственной дальности, без прежнего лимита 8 studs.
- **Fast Interact:** переключатель ИЛИ удержание F. Больше не нужно одновременно включать функцию
  и удерживать бинд. Бинды меняются через значок рядом с переключателем.
- **Ignore List:** выбранное означает «пропускать». У Auto и Fast остаются отдельные фильтры.
- **Prompt reach multiplier:** 1..2, применяется сразу, только к текущей комнате. При значении >1
  prompts остальных комнат временно отключаются; при входе туда или сбросе multiplier они восстанавливаются.
- **Instant prompts / Prompt clip:** отдельные настройки. Меню, ввод текста, потеря фокуса и смерть
  приостанавливают автоматическое взаимодействие.

Без функции исполнителя fireproximityprompt используется резервный путь из Abysall:
выбранный prompt временно переносится к камере, активируется и возвращается на место. Временные
изменения дальности/LOS не означают постоянный reach через весь уровень; до переноса проверяются
исходная дальность, доступность и комната. При выключении/смене комнаты/выгрузке состояние восстанавливается.

Уведомления теперь анимируются TweenService, а не обновлением координат 5 раз в секунду.
Поясняющие подписи под функциями убраны; авторство FireBacon (bocaj111004), MIT и рабочие статусы сохранены.

Настройки v0.4.3 находятся в отдельной папке; старые конфиги автоматически не подхватываются.
Проверьте сначала чистую сборку без старого конфига.

## Ограничения

Компиляция и локальные mock-тесты пройдены, но живой тест в DOORS не проводился. Тестовые Tween-объекты
проверяют параметры/очистку, а не фактическую плавность в Roblox. Сервер может отклонять взаимодействия.
Неполные CurrentRoom/ParentRoom и изменённая структура prompts остаются возможными причинами несовместимости.
При новом сбое полезны версия из Home, название этажа, исполнитель, используемые настройки и конкретный предмет.
