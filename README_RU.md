# ClaudeHub JJS v0.2.0

Обычный Obsidian. DOORS и универсальный модуль не изменены.

## Установка

Замените `JJS.luau` в корне `dima345ccnnmm/ClaudeHub`, ветка `main`.
Если загрузчик v1.2.0 из предыдущего архива уже установлен, менять его не нужно. Его копия включена для удобства.
В текущей игре сначала выгрузите старый ClaudeHub через Unload, затем запустите загрузчик снова.
Архив сам ничего не публикует в GitHub.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dima345ccnnmm/ClaudeHub/main/Loader.luau"))()
```

## Изменения

- Удалены Third Person, Waypoints и тренировочный таймер. Время сессии в Home осталось информационным показателем.
- Вместо фиксированного буста — включаемый WalkSpeed с ползунком 0–120. При выключении/выгрузке восстанавливается прежняя скорость, если значение всё ещё принадлежит модулю.
- Infinite Jump теперь дополнительно задаёт вертикальную скорость корневой детали персонажа: не полагается только на ChangeState. Сохраняет горизонтальную скорость, обрабатывает JumpRequest и Space с защитой от повторного вызова.
- Freecam обновляет камеру позднее стандартного контроллера, задаёт Focus, при доступности отключает стандартный PlayerModule Controls и восстанавливает его. При включении закрывает меню, чтобы ввод сразу работал.
- Anti Camera Shake — сглаживание высокочастотной тряски CFrame. Сила регулируется; может сглаживать и обычные движения камеры. Это не перехват всех игровых CameraShaker/кат-сцен.
- Вкладка Servers: публичные серверы текущего Place, сортировка по заполненности/пингу, страницы, Join Selected, Hop to First Listed, Rejoin и переход по Job ID. Список загружается только по кнопке, текущий и заполненные серверы исключаются. До 500 записей. Hop выбирает первый сервер после выбранной сортировки.
- Combat: Face Target, выбор ближайшего/ближайшего к прицелу/заданного игрока, дальность, скорость разворота, прогноз движения, проверка стены, фильтр команды, подсветка цели и Combat HUD.
- Экспериментальные Auto Block / Auto Counter по настраиваемым ID анимаций атак. Подробности ниже.
- Метки игроков, FOV, освещение, темы/конфиги и перетаскивание HUD сохранены.

## Face Target — «как на геймпаде»

Функция поворачивает модель вашего персонажа по горизонтали к выбранной цели. Она не подключает виртуальный геймпад, не меняет InputDevice и не увеличивает hitbox/дальность удара.

1. Выберите Target Mode; для Selected укажите игрока.
2. Включите Face Target.
3. При необходимости включите Wall Check / Hide Teammates.

При открытом меню, чате, потере фокуса, Freecam или Spectate поворот и защита приостанавливаются. AutoRotate восстанавливается при отключении и выгрузке.

## Auto Block и Auto Counter: обязательная настройка

В модуле намеренно нет неподтверждённого «универсального списка атак». Без списка Attack Animation IDs защита не включается.

1. Выберите противника через Combat → Target Mode: Selected → Selected Player. Подойдите в пределах Target Range.
2. Пока он выполняет нужный удар, нажмите Scan Target Animations. Кнопка считывает только текущие проигрываемые анимации выбранного противника.
3. Выберите именно анимацию атаки в Observed Attack и нажмите Add Selected Attack ID. Повторите для других атак. Если ID известны, их можно вставить в Attack Animation IDs через пробел/запятую.
4. Не добавляйте idle, ходьбу, бег или реакцию на получение урона: это вызовет ложные срабатывания. Считывание само не отличает их от атак.
5. Настройте Defense Range и включите Auto Block. Блок отправляет нажатие F при распознавании настроенной анимации рядом у противника, смотрящего в вашу сторону. Block Hold задаёт задержку отпускания после исчезновения угрозы. Для разворота к цели отдельно включите Face Target.
6. Для Auto Counter выберите Counter Ability Key — клавишу вашей настоящей контр-способности (1/2/3/4/R). Модуль не определяет выбранного персонажа, наличие контры и её серверный cooldown. Counter Interval — минимальный интервал попыток; подберите его под реальное время восстановления способности.
7. Закройте меню для работы автоматики. Auto Counter пробует контру один раз на распознанное проигрывание атаки; если включён Auto Block, он используется, когда контра не отправляется.

Defense не анализирует hitbox, не знает, блокируется/контрится ли конкретная атака, и не гарантирует тайминг или защиту от всех приёмов. Зависит от репликации анимаций, сетевой задержки и поддержки VirtualInputManager окружением. Если отправка клавиши запрещена, функция отключается с уведомлением. Никаких игровых remote-вызовов или обхода античита нет.

## Клавиши

| Клавиша | Действие |
| --- | --- |
| RightControl | Меню |
| V | WalkSpeed |
| J | Infinite Jump |
| H | ESP игроков |
| X | Face Target |
| B | Auto Block |
| C | Auto Counter |
| F6 | Freecam |
| F7 | Spectate |
| F9 | Combat HUD |

Бинды меняются на самих переключателях; отдельного столбика нет.
Freecam: WASD, Q/E вниз/вверх, Shift ускоряет, удержание ПКМ поворачивает камеру. RightControl открывает меню; движение freecam при открытом меню приостанавливается.
Все функции по умолчанию выключены. Автозагрузка конфигураций отключена; Auto Block/Counter не сохраняются включёнными.

## Ограничения и проверки

Это клиентский модуль. Сервер JJS может корректировать WalkSpeed, прыжки, ориентацию или игнорировать синтетический ввод. Название функции не означает гарантированной работоспособности или безопасности от санкций. Ограничения публичного Roblox API/окружения могут мешать загрузке серверов; приватные серверы не обходятся.

Оба исходника проходят Luau compilation. Локальные тестовые заглушки проверяют удаление старых функций, WalkSpeed/восстановление, прыжковый импульс и ввод, выбор/фильтры цели, клавиши защиты и отпускание при выключении/выгрузке, отказ ввода, дедупликацию контры, Freecam/смену камеры/восстановление Controls, сглаживание, серверные страницы/сортировку/переход/ошибки, HUD и респавн.
Это не запуск в настоящем JJS. Исправления Infinite Jump/Freecam и экспериментальную защиту нужно проверить непосредственно в игре.

UI: Obsidian (deividcomsono, MIT). Библиотека и дополнения загружаются с официального GitHub при запуске. Файловые конфиги требуют поддержки окружения.
