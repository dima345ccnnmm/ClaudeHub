# ClaudeHub JJS v0.2.1 — Auto Block от Zorcex

## Что перенесено

Логика Auto Block адаптирована из `Auto-Blocking.lua` автора Zorcex:
https://github.com/Zorcex/JJS-Script/blob/7efe3975d969c39e159f07db4e44669c879cda96/Auto-Blocking.lua

Перенесены основные функции: поиск BlockService, обработка OnClientEvent, определение близкого персонажа из аргументов события, поворот к нему, вызовы Activated / Deactivated и удержание блока (по умолчанию 0.5 с).

Это адаптация под жизненный цикл ClaudeHub, а не запуск чужого хаба: Tora-Library, внешнее окно, _G-переключатели и уничтожение чужого интерфейса не перенесены.
Автор указан в комментарии исходника, Home, Combat и THIRD_PARTY_NOTICES.txt.

## Важное ограничение совместимости

Исходник Zorcex использует конкретный путь:

```
ReplicatedStorage.Knit.Knit.Services.BlockService.RE.Activated
ReplicatedStorage.Knit.Knit.Services.BlockService.RE.Deactivated
```

Оба объекта должны быть RemoteEvent. Наличие этого пути в актуальном JJS НЕ подтверждено запуском в игре.

В Combat есть кнопка **Check Block API**. Если пишет unavailable, нужных событий нет: Auto Block не включится, а остальные части ClaudeHub продолжат работать. В таком случае перенос исходника сам по себе не решает несовместимость с игрой; нужен актуальный рабочий исходник/проверенные игровые события. Модуль не перебирает и не выдумывает альтернативные remote-вызовы.

Метод оригинала — эвристика: реакция на входящие RemoteEvent, в аргументах которых передан близкий персонаж. Это не распознавание всех атак и может давать ложные срабатывания либо пропускать атаки, если игра не передаёт такие аргументы.

## Auto Counter

Отдельной открытой реализации Auto Counter в перечисленных файлах этого репозитория не найдено. `Auto-Blocking.lua` реализует только блок. Обфусцированный `Invisible-Block.lua` не был выполнен и не использовался как неподтверждённая реализация контры.

Старая неработающая экспериментальная контра и ручной список ID анимаций удалены. В интерфейсе есть явная пометка, что исходник Auto Counter отсутствует; пустого рабочего на вид переключателя нет.
Для переноса контры нужен отдельный читаемый рабочий исходник или точная ссылка на её реализацию.

## Использование

1. Выгрузите предыдущий ClaudeHub через Unload.
2. Замените `JJS.luau` в корне репозитория `dima345ccnnmm/ClaudeHub`, ветка `main`.
3. Loader v1.2.0 не изменён; копия включена для удобства. DOORS и универсальный модуль не затронуты.
4. Перезапустите привычный загрузчик:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dima345ccnnmm/ClaudeHub/main/Loader.luau"))()
```

5. Combat → Check Block API. Если доступно — включите Auto Block (Zorcex), настройте Block Distance / Block Duration и закройте меню.

Attack Animation IDs и VirtualInputManager для автоблока больше не нужны. Поворот к атакующему выполняет сам автоблок, отдельно включать Face Target не обязательно.
Учитываются Combat Wall Check / Hide Teammates. Во время меню, чата, потери фокуса, Freecam и Spectate блок приостанавливается/отпускается.
При выключении подписки отключаются, блок отпускается, AutoRotate восстанавливается с учётом Face Target. При респавне/удалении персонажа и выгрузке блок также отпускается.
Включённый Auto Block не сохраняется в конфиги; по умолчанию он выключен. Клавиша по умолчанию — B, меню — RightControl.

Архив не публикует файлы в GitHub автоматически. Перед публичным размещением обратите внимание на отсутствие заявленной лицензии оригинала (см. notices).

## Остальные функции

Сохранены Servers, WalkSpeed, Infinite Jump, ESP игроков, FOV, Freecam/Spectate, Anti Camera Shake, Face Target, Combat HUD, темы и ручные конфиги. Третье лицо, тренировочный таймер и точки не возвращены.
Ограничения v0.2.0 сохраняются: клиентские свойства/ввод может корректировать сервер; сглаживание камеры не удаляет все игровые эффекты; функциональность в настоящем JJS ещё нуждается в проверке.

## Проверки

JJS.luau и Loader.luau проходят компиляцию Luau.
В локальных заглушках проверены точный путь BlockService, отсутствие API, подписка/отписка RemoteEvent, исключение block/emote-событий, дальность/стены/команда, динамические RemoteEvent без двойных подписок, вызовы без аргументов, длительность/отпускание блока, поворот/AutoRotate, респавн/потеря фокуса/Freecam, удаление API и ошибка вызова.
Также выполнена регрессионная проверка движения, прыжка, ESP, Servers и Freecam.
Это тесты клиентской логики, а не подтверждение успешного блока в настоящей игре.
