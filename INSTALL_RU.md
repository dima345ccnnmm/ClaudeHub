# Установка ClaudeHub DOORS v0.4.1

## Обновить три скрипта в корне репозитория

1. `Doors.luau` — игровой модуль.
2. `DoorsLobby.luau` — НОВЫЙ отдельный модуль лобби.
3. `Loader.luau` — универсальный загрузчик v1.1.0.

Также обновите `THIRD_PARTY_NOTICES.md` и `CHANGELOG.md`. Ваш универсальный `ClaudeHub.luau` менять не нужно.
Файлы в этом архиве ещё не опубликованы на GitHub автоматически.

## Запуск

Перезайдите в игру перед проверкой. Это важно: старый Main.luau мог оставить обработчики,
которые продолжают выводить ошибки даже после появления нового меню.
Запускайте только обновлённый ClaudeHub Loader, не исходный Abysall Main.luau параллельно.

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dima345ccnnmm/ClaudeHub/main/Loader.luau"))()
```

Проверьте версию в Home: `v0.4.1`. Пока новые файлы не загружены в репозиторий,
эта ссылка продолжит загружать старые файлы, а не содержимое архива.

- Place ID `6516141723` → `DoorsLobby.luau`.
- Остальные места вселенной DOORS → `Doors.luau`.
- Другие игры → прежний `ClaudeHub.luau`.

После телепорта из лобби в игру загрузчик нужно запустить снова. Автозапуск при телепорте не установлен.

## Исправления

**Third Person:** Visuals → Camera → Third person, бинд T. Обычная Scriptable-камера DOORS теперь допускается;
смещение применяется поздно в кадре. При отключении возвращаются камера и прозрачность персонажа.
Во время Hiding / AnimatingClient функция приостанавливается.

**Dupe:** Visuals → ESP → Dupe detection. По умолчанию Strict: требуется Hidden с TouchTransmitter.
Имя FakeDoor/DoorFake само по себе больше не считается доказательством Dupe.
Если на старом этаже триггер не реплицируется, возможен пропуск настоящего Dupe;
Compatible: Hidden hitbox менее точен и может вернуть ложные срабатывания на декоре.

**Ошибки из лога:** строки 1125 и 1548 совпали с присланным исходным Main.luau
(`Toggles.DisableIdleKick.Value` и прямое `Main_Game.PromptService`). В новой сборке нет этих прямых
непроверенных обращений и не загружается исходный Main.luau.

## Лобби

- Auto Join использует выбранного игрока и его текущий лифт; при отсутствии цели не спамит ElevatorExit.
- Quick Play и Create Elevator только отправляют запросы, которые игра вправе отклонить.
  Доступ к закрытым/устаревшим режимам не обещается; ID новых этажей не выдумываются.
- Cycle Achievements работает только с разблокированными значками и корректно обрабатывает пустой список.
- Коды из образца могут быть просрочены. Запросы кодов запускаются явно и могут быть остановлены.
- Все автоматизации изначально выключены. Настройки лобби хранятся отдельно от игры.
