# ClaudeHub DOORS v0.4.2 — установка

## Что заменить

Если v0.4.1 уже установлена, замените в корне репозитория **Doors.luau** и обновите
THIRD_PARTY_NOTICES.md / CHANGELOG.md. Loader.luau v1.1.0 и DoorsLobby.luau v0.4.1 в архиве
не изменены. Универсальный ClaudeHub.luau менять не нужно.

Файлы архива НЕ публикуются в GitHub автоматически. Пока Doors.luau не обновлён
в репозитории, прежняя ссылка загрузит прежний игровой модуль.

Перезайдите в игру, затем запустите:

```lua
loadstring(game:HttpGet("https://raw.githubusercontent.com/dima345ccnnmm/ClaudeHub/main/Loader.luau"))()
```

В игровом Home должна быть версия v0.4.2. Версия отдельного лобби остаётся v0.4.1.
После телепорта загрузчик нужно запустить повторно; автозапуск не установлен.

## Новое поведение

- **ESP и уведомления:** Seek и Screech теперь отдельные сущности в обоих списках выбора.
  Если загрузили старый сохранённый конфиг, отметьте эти новые пункты вручную.
  Объекты/детали Eyes внутри Screech/Seek, инструменты и декор не считаются сущностью Eyes.
- **Visuals → ESP Settings → Room visibility:** по умолчанию Current room. Объекты старой
  комнаты скрываются, а при возвращении появляются снова. Глобальные сущности без привязки
  к комнате остаются видны. Если CurrentRoom не реплицирован, используется видимость загруженных
  объектов. All loaded rooms возвращает прежний режим. Чужой LatestRoom не используется.
- **General → Automation → Auto Interact:** включите переключатель для постоянной работы
  ИЛИ удерживайте R для временной работы. Бинд меняется через значок рядом с переключателем.
  Меню должно быть закрыто; ввод текста и потеря фокуса приостанавливают работу.
- **Ignore List:** выбранный пункт означает «пропускать». По умолчанию выбраны Glitch Fragments,
  Jeff Items, Dropped Items. Есть также Currency, Minecarts и Locks. Список Fast Interact отдельный.
- **Ящики и сундуки:** учитывается положение модели, а её ручка/фасад не принимаются за постороннюю
  стену. Закрывающие действия пропускаются, чтобы автоматизация не закрывала открытый ящик.
  Дальность и Enabled остаются ограничены самим prompt; сервер может отклонить запрос.
- **Уведомления:** стили Abysall, Doors, STX — разные локальные макеты по образцу, не запуск
  стороннего notification-loader. Имеются отдельные заголовок/текст, полоса времени, крестик,
  перетаскиваемая шапка и Clear notifications / Reset notification position.

## Ограничения

Компиляция и локальные mock-тесты пройдены. Проверка в живом Roblox/DOORS не проводилась.
Неизвестные вложенные варианты Eyes могут быть пропущены: лучше пропуск, чем ложные глаза
на каждом предмете. Поддержка новых этажей Archives/Stairwell здесь не заявляется.
